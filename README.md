# FácilPost · Calendário de publicações

A tela principal mostra as publicações da Página do Facebook selecionada em um calendário mensal. Clique em um dia para consultar os horários ou criar uma publicação. Selecione um post para abrir a prévia, editar o texto ou consultar suas métricas.

Os arquivos em `public/` são servidos diretamente pelo nginx. O frontend chama `/api/` no mesmo domínio usado pelo navegador. As credenciais da Meta são configuradas no backend.

[Instalação na VPS e configuração da Meta](https://github.com/ViniciusdAvilla/FacilPost-Backend/blob/main/deploy/README.md)
